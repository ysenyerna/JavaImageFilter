## Java Image Filter 
Simple Java program that takes an image file and applies multiple filters.
### Explanation
The program takes the file named `original.jpg` from the main project folder, then creates copies of the file applying grayscale, inverted, and brightened filters.
### Instructions
To run the program, open the project folder in the terminal, then run the commands `javac Main.java` and `java Main`.  
Replace the `original.jpg` file with another image file to apply the filters to that image.
